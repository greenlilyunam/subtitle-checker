# Design 文件夹说明

当前文件夹提供开发用结构线框：

- `upload-page-wireframe.svg`：上传页
- `workspace-wireframe.svg`：字幕检查工作台
- `export-modal-wireframe.svg`：导出确认弹窗

这些线框只用于确定区域、信息层级和关键控件。项目不等待 Stitch／Figma 高保真稿，Codex 应根据根目录 `VISUAL-PROMPT.md` 自主完成视觉设计并直接编码。

开发优先级：

1. `RULES.md`：规则行为
2. `PRD.md`：产品范围
3. `UI-SPEC.md`：交互与视觉规范
4. `VISUAL-PROMPT.md`：视觉方向、禁止项和浏览器复核流程
5. 本文件夹的 wireframe：结构参考

Codex 完成页面后，应以真实浏览器渲染结果作为视觉依据，而不是在本文件夹继续生成不可交互的静态 UI 图片。
