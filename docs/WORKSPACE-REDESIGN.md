# 校对工作台改版验收

本次界面调整以用户确认的“理想工作台结构”为准，替代早期 UI 文档中的常驻三栏布局。规则引擎、导出行为、术语优先级和风险限制沿用原实现。

## 实现

- 顶部：文件名、已处理进度、撤销/重做、取消任务、完成并导出。
- 左侧：待处理、已处理、全部；高级筛选按需展开，支持处理结果、问题类型，本土化模式另有风险等级。
- 中间：字幕对照、主要原因、接受/忽略/编辑；普通建议详情折叠，高风险与冲突详情展开。
- 右侧：规则/术语表抽屉，支持 Esc 关闭、焦点限制和关闭后焦点返回。
- 支持从具体修改原因编辑命中的企业术语。
- 规则变更后关闭抽屉仍有重新检查提示；冲突有独立可见提示。
- 取消任务后清空当前工作与旧提示；原字幕文件保持不变。

## 验证证据

- 格式检查、lint、TypeScript 和生产构建通过。
- 10 个测试文件、41 个领域单元测试全部通过。
- P0 浏览器路径：上传 mixed-issues、启用三规则、接受两项、忽略一项、手动编辑、撤销、导出并重新导入，通过；UTF-8 无 BOM、仅 CRLF。
- 台湾繁体浏览器路径：13 条建议，批量接受后输出与 custom-glossary 期望完全一致，受保护内容不变。
- 英文浏览器路径：Excel 导入 2 条，生成 2 条建议，低风险接受，高风险手动补译，导出 `_en.srt`。
- 新工作台路径：高级筛选、三状态、撤销/重做、术语就地编辑、规则变更提示、抽屉 Esc/焦点返回、导出确认通过。
- 1440×960：中间阅读区 1250px，页面宽度 1440px，无横向溢出。
- 1024×768：中间阅读区 854px，页面宽度 1024px，无横向溢出。
- 已完成两轮真实 Chrome 视觉检查；截图与结构化验收结果保存在本地 `artifacts/focused-workspace/`。
- 新工作台与本土化验收记录中，浏览器异常和对外文件请求均为 0。

## 发布

GitHub Pages 工作流对每次 main 推送执行格式、lint、单元测试和生产构建后发布。个人导入文件、截图和下载文件不进入仓库。

## 已知限制

- 桌面端支持范围从 1024px 开始。
- 会话状态刷新后清空。
- 离线转换字典使生产脚本较大，Vite 会给出非阻断的体积提示。
