# 字幕检查器 P1：台湾繁体本土化开发交接包

本文件包用于在已经完成的 P0 字幕检查器上，继续开发 P1 本土化模块。

## 本次范围

P1 首版处理的是：

> 导入已有的简体中文字幕 → 选择“台湾繁体”目标地区 → 根据字符、地区用语和企业术语表生成建议 → 用户逐条确认 → 保留原时间轴导出新的 SRT。

本阶段不做自动英文翻译，也不调用外部 AI API。这样可以先验证用户是否需要“可控、可解释、可复核”的本土化流程。

## 交给 Codex 的方式

1. 将本文件夹放进已经完成的 P0 项目根目录，建议路径为 `docs/p1-localization/`。
2. 不要用本文件包覆盖 P0 已有的 `AGENTS.md`、PRD 或源代码。
3. 打开整个 P0 项目文件夹，而不是只打开本文件包。
4. 把 `P1-CODEX-PROMPT.md` 全文发送给 Codex。
5. Codex 应先检查现有项目的数据结构、测试与视觉系统，再做增量实现。

## 已作出的产品决定

- 首个目标语言固定为：简体中文（中国大陆）→ 繁体中文（中国台湾）。
- 用户上传的是已有中文字幕，不做语音识别和视频转字幕。
- 纯前端、本地处理，无账号、后端、数据库和云端保存。
- 可以使用离线字符转换能力，但不得把字幕发送到外部服务。
- 企业自定义术语表的优先级最高。
- 品牌名、产品名、URL、邮箱、版本号和型号可以被保护，不应被误改。
- 字符转换、地区用词与表达调整均以“建议”呈现，用户确认后才进入导出内容。
- 保留原字幕序号、时间码、换行和排序。
- P0 功能必须继续可用，P1 是新增模式，不是重写产品。

## 本阶段刻意不做

- 英文或其他语言自动翻译
- 自由改写整句文案
- 调用大模型判断语气
- 视频/音频识别字幕
- 自动调整时间轴
- 登录、历史记录、云端术语库、团队协作和剪映插件

这些能力继续保留在后续版本，不应由 Codex 自行扩展。
