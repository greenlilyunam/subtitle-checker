# P1 UI 说明：台湾繁体本土化

## 1. 设计目标

P1 延续 P0 的“专业字幕校对工作台”视觉系统。不要新建一套完全不同的产品，也不要把本土化做成聊天窗口。

用户需要快速回答四个问题：

1. 当前从什么语言处理到什么地区？
2. 哪些字幕需要改，为什么？
3. 这条建议来自内置规则还是企业术语表？
4. 导出时还有哪些风险未处理？

## 2. 视觉原则

- 继续使用 P0 的字体、颜色、圆角、阴影、按钮和卡片组件。
- 蓝色代表主要操作，绿色代表已接受，橙色代表待确认，红色只用于冲突和错误。
- 不使用紫色 AI 渐变、聊天气泡、魔法棒主视觉和“AI 正在思考”等表达。
- 本土化建议应像校对证据，不像自动生成内容。
- 差异高亮必须可读：删除内容浅红，新增内容浅绿，术语命中可使用淡蓝下划线或标记。
- 1440×960 为主要桌面尺寸；1024×768 下仍能完成任务。

## 3. 页面改动总览

P1 在已有 P0 上增加：

1. 上传页：任务模式选择
2. 上传成功后：本土化设置面板
3. 工作台：语言方向、问题类型和原因展示
4. 右侧栏：规则/术语表双标签
5. 弹窗：术语表导入结果
6. 弹窗：本土化导出确认

## 4. 上传页

### 4.1 模式选择

在原上传卡片上方增加分段选择器：

- `基础检查`
- `本土化`

默认沿用产品当前决定；如果没有既有状态，默认选择“基础检查”，避免 P1 改变 P0 用户习惯。

选择“本土化”后：

- 主标题：`上传字幕，创建台湾繁体版本`
- 副标题：`检查简繁字符、地区用语和企业术语，所有修改均由你确认`
- 上传按钮保持 `选择 SRT 文件`
- 隐私说明：`字幕和术语表只在当前浏览器中处理`

### 4.2 上传约束

- 仍只支持单个 `.srt`。
- 解析失败沿用 P0 错误组件。
- 若字幕没有检测到中文，不阻止上传，但提示：`未检测到足够的中文内容，请确认源语言。`

## 5. 本土化设置面板

上传成功后、进入正式检查前显示。可采用居中面板或工作台右侧设置页，但不要增加新的营销式页面。

### 5.1 基本设置

标题：`设置本土化规则`

语言方向：

- 源语言：`简体中文（中国大陆）`
- 箭头
- 目标语言：`繁体中文（中国台湾）`

首版两个选择器均为固定值。不要显示尚未支持的可选语言。

### 5.2 规则开关

默认开启：

- 简体字转繁体字
- 台湾地区常用词
- 软件与企业场景用语
- 标点和中英文空格检查
- 保护链接、邮箱和版本号
- 检查疑似漏改和术语冲突

每项有一行简短说明。关闭某项只影响本次检查。

### 5.3 术语表

卡片标题：`企业术语表（可选）`

内容：

- 说明：`导入客户或企业指定用词，自定义术语会优先于内置规则。`
- 次级按钮：`导入 CSV 或 JSON`
- 文字链接：`下载示例`
- 未导入状态：`当前使用内置台湾企业用语`
- 已导入状态：显示文件名、有效条目数、冲突数和 `查看术语` 操作

底部：

- 次级按钮：`更换文件`
- 主按钮：`开始本土化检查`

## 6. 本土化工作台

整体继续使用 P0 的顶部工具栏、左侧筛选、中间字幕卡片和右侧规则栏。

### 6.1 顶部工具栏

在文件名旁增加语言胶囊：

`简中 → 台湾繁中`

统计信息改为：

- 建议总数
- 已接受
- 已编辑
- 待处理
- 冲突

右侧按钮：

- 撤销
- 重做
- `导出台湾繁中 SRT`

若有冲突，导出按钮旁显示红色或橙红色提示：`还有 1 项术语冲突`。

### 6.2 左侧筛选栏

处理状态：

- 全部建议
- 待确认
- 已接受
- 已忽略
- 已编辑
- 冲突

问题类型：

- 简繁字符
- 台湾用词
- 企业/技术用语
- 标点与空格
- 自定义术语
- 疑似漏改

可增加风险筛选：低、中、高。若空间不足，放在筛选按钮弹层内。

### 6.3 字幕卡片

卡片顶部：

- 复选框
- 字幕序号
- 时间码
- 问题类型标签
- 风险等级
- 状态

主体：

- `原字幕`
- `台湾繁中建议`
- 差异高亮

原因区：

- 示例：`“软件”在台湾软件产品语境中通常使用“軟體”`
- 来源徽标：`内置用语`、`企业术语表`、`字符转换`、`格式规则`
- 多个命中时显示 `共 3 项修改`，可展开查看逐项原因

底部操作：

- `接受建议`
- `忽略`
- `手动编辑`
- `查看详情`

高风险冲突卡片：

- 红色左边框或浅红警示区
- 明确列出冲突目标词和对应术语条目
- 不显示可直接批量接受的状态
- 提供 `选择用词` 和 `编辑术语表`

### 6.4 批量操作

- 选中项目后显示 `批量接受`、`批量忽略`。
- 全是低风险时可直接操作。
- 含中风险时弹出确认：`所选内容包含 3 项表达调整，请确认后继续。`
- 含高风险冲突时禁用批量接受，并说明原因。

## 7. 右侧栏

增加两个标签：

- `本土化规则`
- `术语表`

### 7.1 本土化规则标签

显示设置面板中的开关，以及：

- 当前方向：简中 → 台湾繁中
- 修改后需点击 `重新运行检查`
- 若存在用户手动编辑，重新运行前弹出保护提示

### 7.2 术语表标签

顶部：

- 搜索框：`搜索源词或目标词`
- `新增术语`
- 更多菜单：重新导入、下载示例、清空自定义术语

列表每行：

- 启用开关
- 源词 → 目标词
- 动作标签
- 优先级
- 编辑/删除

内置术语与自定义术语视觉区分：

- `企业术语` 用蓝色徽标
- `内置用语` 用灰色徽标

自定义术语覆盖内置词时显示：`已覆盖内置规则`。

## 8. 术语表导入结果弹窗

宽度约 560px。

标题：`术语表导入完成`

摘要：

- 有效条目 12
- 已去重 2
- 无效条目 1
- 冲突 1

若存在问题，列表显示行号、原因和建议处理方式。例如：

- `第 8 行：replace 类型缺少 target_term`
- `第 12、13 行：“报警信息”存在相同优先级的不同目标词`

按钮：

- `返回修改文件`
- `使用有效条目继续`

无效行不能让整个导入失败。

## 9. 导出确认弹窗

标题：`确认导出台湾繁中字幕`

摘要：

- 已接受建议
- 已手动编辑
- 已忽略
- 尚未处理
- 术语冲突

有未处理项时显示橙色提示；有冲突时显示更强提示：

`仍有 1 项术语冲突。未处理内容将保留原字幕。`

文件设置：

- 文件名：`原文件名_zh-TW.srt`
- 格式：SRT
- 编码：UTF-8
- 固定说明：`保留原字幕序号、时间码和换行`

按钮：

- 取消
- 返回继续检查
- 继续导出

## 10. 关键状态

### 检查中

- 标题：`正在生成台湾繁中建议`
- 当前步骤可显示：保护专有内容、转换繁体字符、匹配地区用语、检查术语冲突
- 不使用“AI 思考中”文案

### 没有发现建议

- 标题：`没有发现需要本土化处理的内容`
- 说明：`该字幕已通过当前启用的台湾繁中规则`
- 操作：导出、调整规则

### 术语表导入失败

- 告诉用户具体原因，如缺少表头、文件编码错误或 JSON 结构错误
- 提供重新选择和下载示例

### 规则重新运行

如有手动编辑，弹窗提供：

1. 取消
2. 保留手动编辑，重新检查其他字幕
3. 放弃当前处理结果并全部重新检查

## 11. 响应式要求

### 1440×960

- 保持三栏工作台。
- 中间字幕卡片为主要视觉区域。

### 1024×768

- 左侧筛选栏可收起。
- 右侧规则/术语表改为抽屉。
- 顶部统计允许压缩为 `待处理 8 · 冲突 1`。
- 接受、忽略、编辑仍始终可见。

### 小于 900px

P1 不要求完整移动端适配。应显示桌面使用提示或提供基本只读布局，不得为了移动端破坏桌面工作流。

## 12. 可用性细节

- 所有颜色状态同时有文字或图标，不能只靠颜色区分。
- 差异高亮满足可读性，不使用低对比度浅字。
- 按钮有 hover、focus、disabled 和 loading 状态。
- 术语表编辑支持键盘操作，弹窗有焦点管理。
- 规则来源和修改原因不能藏在只有悬停才能看到的位置。
- 高风险冲突必须在左侧筛选、字幕卡片和导出弹窗三个位置可见。
