# P1 验收标准

## 1. 集成验收

- [ ] 在现有 P0 项目上增量开发，没有重建或删除 P0 功能。
- [ ] 基础检查模式仍可完成原有上传、检查、确认和导出流程。
- [ ] 本土化模式可以独立运行，不污染基础检查规则状态。
- [ ] 遵循现有项目的目录、状态管理、组件和样式约定。

## 2. 核心流程

- [ ] 用户可选择“本土化”模式并上传单个 SRT。
- [ ] 界面明确显示“简体中文（中国大陆）→繁体中文（中国台湾）”。
- [ ] 用户可选择本土化规则并运行检查。
- [ ] 用户可导入 CSV 或 JSON 术语表。
- [ ] 用户可逐条接受、忽略和手动编辑建议。
- [ ] 用户可对低风险建议批量接受或批量忽略。
- [ ] 中风险批量接受有二次确认。
- [ ] 高风险冲突不能批量接受。
- [ ] 用户可撤销、重做并重新运行检查。
- [ ] 用户可导出 `_zh-TW.srt` 文件。

## 3. 规则准确性

- [ ] `samples/localization-input.srt` 在默认设置下，全部接受后的结果与 `samples/localization-expected-default.srt` 完全一致。
- [ ] 导入 `glossary/example-glossary.csv` 后，全部接受的结果与 `samples/localization-expected-custom-glossary.srt` 完全一致。
- [ ] 导入示例术语表后，受保护的 `思倍云`、`SmartInspect V2.1`、URL 和邮箱保持不变。
- [ ] `数据库` 按长词优先正确处理为 `資料庫`。
- [ ] 自定义术语覆盖内置用语。
- [ ] 相同源词、相同最高优先级、不同目标词产生高风险冲突。
- [ ] 保护项不会被字符转换或地区词规则二次处理。
- [ ] 多行字幕保留原换行位置。
- [ ] 已是台湾繁体的测试文件不会出现持续二次修改。
- [ ] 本土化处理具备幂等性。

## 4. 术语表

- [ ] CSV 与 JSON 示例都能成功导入。
- [ ] 支持 `replace`、`suggest`、`protect`、`warn` 四种动作。
- [ ] `enabled=false` 的条目不参与匹配。
- [ ] 优先级为 0–100 整数，越大越优先。
- [ ] 无效行被单独报告，不阻止其他有效行。
- [ ] 完全重复条目去重并提示。
- [ ] 无表头、非法 action、缺少目标词、非法优先级有明确错误。
- [ ] 用户可在当前会话新增、编辑、停用和删除术语。
- [ ] 刷新后无需保留术语和字幕。

## 5. 字幕完整性

- [ ] 导出前后字幕块数量一致。
- [ ] 字幕序号完全一致。
- [ ] 开始与结束时间码完全一致。
- [ ] 字幕块顺序完全一致。
- [ ] 除用户接受或手动编辑的文本外，无其他内容改变。
- [ ] 导出的 SRT 为 UTF-8，并可被本工具重新导入。
- [ ] 导出不会覆盖原文件。
- [ ] 已忽略和未处理的字幕导出原文。

## 6. 隐私与边界

- [ ] 字幕和术语表仅在浏览器本地处理。
- [ ] Network 检查中不存在向第三方发送字幕或术语内容的请求。
- [ ] 不新增后端、数据库、登录或外部 AI API。
- [ ] 不实现英文翻译、视频识别、时间轴调整或团队协作。
- [ ] 不在日志中输出完整字幕和术语表内容。

## 7. UI 与可用性

- [ ] 视觉延续 P0，而不是另一套模板。
- [ ] 1440×960 下三栏布局清晰，无横向溢出。
- [ ] 1024×768 下可通过收起/抽屉完成全部核心操作。
- [ ] 原字幕、建议文本和差异可一眼区分。
- [ ] 每条建议显示原因、来源、风险和状态。
- [ ] 高风险冲突在筛选、卡片和导出弹窗中均可见。
- [ ] 不只依靠颜色表达状态。
- [ ] 键盘焦点、弹窗焦点和禁用状态正确。
- [ ] 上传失败、导入失败、无建议、检查中、导出警告状态完整。

## 8. 自动化测试

至少包含：

- [ ] 术语表 CSV 解析测试
- [ ] 术语表 JSON 解析测试
- [ ] 无效行与去重测试
- [ ] 保护片段测试
- [ ] 最长词优先测试
- [ ] 自定义术语覆盖测试
- [ ] 同优先级冲突测试
- [ ] 简繁字符转换测试
- [ ] 地区用词规则测试
- [ ] 多行字幕与换行测试
- [ ] 幂等性测试
- [ ] 接受/忽略/编辑后的导出测试
- [ ] 时间码与字幕数量不变测试
- [ ] P0 回归测试

## 9. 完成条件

- [ ] lint 通过。
- [ ] 单元测试和已有 P0 测试全部通过。
- [ ] 生产构建通过。
- [ ] 在真实浏览器中完成 1440×960 和 1024×768 两种尺寸检查。
- [ ] 用包内样例完成一次完整手工验收并记录结果。
- [ ] README 说明如何运行、测试 P1 以及导入术语表。
- [ ] 汇报已知限制，不把未实现语言描述成已支持。
